InkManager

Digital Studio System

Sistema de gestión para estudios de tatuaje con un body map 3D interactivo donde marcás cada tatuaje en su posición exacta sobre un modelo humano rotable.

  • Body map 3D con raycaster click-to-mark y markers persistentes
  • CRM de clientes + calendario drag & drop con FullCalendar
  • PHP vanilla MVC propio — sin framework, sin Composer, sin build step
  • Identidad visual completa: splash intro, tipografía editorial, monograma SVG
PHP 8.2 MySQL Three.js Tailwind Railway
